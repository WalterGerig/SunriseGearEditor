# Sunrise Gear Editor

An unofficial Gear Editor for Sunrise that allows weapons and armor to be edited live while the game is running.

## Bug Reporting

If you encounter any bugs or game crashes Please open a Issue in this github repo and try to explain how the bug happend or the game crashed

## Features

### Weapons
- Edit weapons live in-game
- Replace a weapon with a completely different weapon
- Change perks, mods, shaders and ornaments
- Apply perks and mods to slots they normally do not belong in
- Mix perk combinations that are normally not possible

### Armor
- Edit armor live in-game
- Replace armor pieces with different armor
- Change mods, perks, shaders and ornaments
- Apply perks and mods without the normal slot restrictions
